# Omarchy Android 一体包

本目录已并入 [Audrey-cn/omarchy-android](https://github.com/Audrey-cn/omarchy-android) 单仓项目。

当前中文介绍、安装方法与快捷键见 [README.md](README.md)，构建与协同开发见[开发指南](../../docs/DEVELOPMENT.md)。下载入口为主仓库的 [Releases](https://github.com/Audrey-cn/omarchy-android/releases)；本地迁移不代表已经发布新安装包。
