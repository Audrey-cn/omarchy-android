# Android Monorepo Implementation Plan

**Goal:** 在 `omarchy-android` 中一起维护桌面核心、免 Root 一体 APK 和 Deck 辅助 APK。

**Architecture:** 保留 `core/`、`runtime/` 与 `install.sh`；将独立 Android 项目完整导入 `apps/android/`，原辅助 APK 移入 `apps/deck/`。镜像构建使用当前 checkout 的核心文件，所有 GitHub Actions 放在根 `.github/workflows/`。

**Tech Stack:** Git subtree、Bash、Python unittest、Android Gradle、GitHub Actions。

## Constraints

- 保留两个项目完整 Git 历史与原始许可证、版权声明。
- 保留 Android 包名和运行栈，不增加产品功能或升级依赖。
- 先在 `codex/unify-android-monorepo` 本地分支交付；旧 App 仓库和远端不改动。
- 构建输入不得从另一个仓库重新下载桌面核心。

## Review Focus

- App 和核心同次修改时，一体包构建使用同一次 checkout。
- Android 普通壳包与含 rootfs 的一体包保持明确区分。
- Gradle 和 APK 路径在迁移后从任意工作目录可定位。
- 大镜像、构建目录和签名密钥不会进入 Git。
- 根 MIT 不覆盖 Android App 原 GPL 声明；旧仓库与提交历史可找回。
