# K20 第二轮收口记录（进行中）

目标：在免 Root 一体 APK 的 K20 Pro Android user 0 环境中，验收配套 Chromium 128、真实 Hermes Agent、首次设置与现有容器更新；仅在浏览器完整验收后启用内置固定版本。独立系统镜像发布、双安装形态及 Android 独立分区安装另轮讨论。

## 已取得的设备证据

- 第二轮前期，旧 `com.omarchy.deck` 已备份并卸载，一体包 `com.omarchy.android` 当时保留；后续首次持续签名迁移见下文。原始 APK 发行归档与私人数据备份见 [版本记录](../VERSIONS.md)。未卸载用户的 Termux / Termux:X11。
- 原 Hermes 模型配置仅迁移所选模型及匹配的 provider/key，未复制其他渠道凭据。实际 Qwen `qwen3.8-flash` 请求 HTTP 200，固定回复检查通过；这单独不构成 Agent 验收。
- Chromium 官方 Linux ARM64 rev1129 ZIP：176724222 bytes，SHA-256 `67aab2cec5a4927667575452a2b6c57566085c154f47f924d6e3efa47f7bd777`；ZIP CRC、ELF AArch64 另行检查通过。配套 Playwright `1.46.1`，浏览器实际报告 `128.0.6613.18`。
- Headless 完整探针通过：导航、DOM、中文填值/点击、截图、Cookie、下载及文件内容。
- Sway 全屏前台下 Wayland 同一完整探针通过。先前后台/画中画状态下截图超时的记录不删除，也不据此添加 GPU 绕过参数；恢复前台后用原参数复测成功。
- 已独立打开 Chromium 图形窗口，并用 `connectOverCDP('http://127.0.0.1:9222')` 连接该实例；公网 Example Domain 标题及截图通过，受控中文表单 `K20 Chromium 128 中文` 的填写、点击、读回及截图通过。此端口只监听 loopback，为本轮独立测试 profile。
- Hermes 指纹限定的 renderer 修补已部署；首次设置页实际保持超过 8 分钟，未再因等待选择触发 45 秒连接失败。核对包内固定安装脚本后 seed bootstrap cache，越过初始下载失败；设置 UV_LINK_MODE=copy 后，Python 依赖完整安装及 import 通过，Desktop 后台服务进入 ready。

## 真实 Agent 验收

固定 Hermes Agent commit 2237be355906fbe6065ce1815711eee52b2d646e 的 AIAgent.run_conversation 使用原 Qwen 模型、地址与密钥，通过 generic custom provider 调用。独立临时 profile 运行 browser-cdp：第 4 轮完成 6 次真实 API 请求、5 次 CDP 操作。中文 DOM、中文输入和点击服务端确认、UUID 新文件下载、完整 55B 内容及 SHA-256、2340×1080 PNG 全部通过独立检查，截图另经人工查看。上述门槛通过后才启用内置构建。

第 3 轮指定自定义下载目录的失败记录保留：Hermes 原始 CDP 每次调用断开 WebSocket，Chromium 128 的 session Disable 恢复默认下载设置。文件真实落入默认 Downloads，内容正确。第 4 轮使用默认目录及每轮唯一文件名，启动前确认文件不存在，未复用旧文件。私网 URL 许可仅用于受控临时 profile；用户主 profile 保持关闭。

## 合并回归发现

Codex 使用精确 a179 回补的 PRoot 后能映射窗口、进入中文登录页并连接内部服务；相同 Codex DEB 在 control PRoot 下退出 133。新版 PRoot 的 Chromium 128 headless 完整探针通过。

之后新建 Wayland 客户端在 classic 与 patched 下均出现 SIGABRT。原生栈定位到 xkb_state_update_mask；协议日志显示 keyboard.enter 和 modifiers 之前缺少 keymap。已稳定复现由 wtype 临时键盘退出触发。恢复入口读取真实 X11 键盘的当前 repeat_delay 和布局索引，同值重新应用并确认状态，没有修改布局、选项或启用状态。wtype 退出后恢复、图形启动前恢复均已接入；K20 上 wtype 包装入口之后直接运行原始完整图形探针通过。没有将无效的 GPU 参数试验写入产品。独立诊断见[键盘恢复报告](sway-virtual-keyboard-recovery-20261123.md)。
